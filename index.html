❖ Proposed Solution

EXPLANATION OF THE SOLUTION

  • Health Monitoring: Tracks heart rate, SpO2, temperature, and movement.
  • Smart Positioning: Uses GNSS + IMU + UWB for reliable location.
  • Resilient Communication: Uses LoRa and stores data during network loss.
  • Emergency Alert: Detects critical conditions and sends SOS + location + health data to the command center.

ADDRESSING THE PROBLEM

  • Health risk → Multi-sensor monitoring detects abnormal vital signs early.
  • GPS failure →GNSS + IMU + UWB provides more reliable positioning.
  • Network failure →LoRa enables long-range communication with local data storage.
  • Emergency →Automatic detection + SOS sends the soldier's location and health status to the command center.

INNOVATION

  • Multi-sensor fusion: Combines GNSS + IMU + UWB instead of relying only on GPS.
  • Resilient communication: Uses LoRa + store-and-forward to maintain data delivery during network outages.
  • Edge intelligence: STM32U575 analyzes health and movement data locally for faster emergency detection.
  • Fail-safe design: Includes battery monitoring, low-power mode, and emergency backup strategy to keep critical functions running during failures.

UNIQUENESS

  • Multi-sensor fusion.
  • GNSS stops working. IMU + UWB gives local tracking only. It tracks movement of a soldier and relative distance between soldiers. Data is stored locally and shared within squad. When one soldier goes out of jamming zone, he sends all relative positions + his live location to basecamp via LoRa.
  • AES-256 encryption for sensor data Public key infrastructure (PKI) for device authentication TLS 1.3 for data between device and server LoRaWAN AES-128 or custom AES-256 for battlefield links HMAC or digital signatures to protect against tampering

POTENTIAL CHALLENGES & RISKS

- Communication Failure: LoRa/GNSS performance can degrade due to terrain, obstacles, or interference.

- Battery Limitation: Multiple sensors and wireless modules can increase power consumption.

- Positioning Errors:IMU drift and UWB/ GNSS inaccuracies can reduce location accuracy.

- Harsh Environment: Heat, rain, dust, and physical impacts may affect the wearable.

- False Alerts: Sensor noise or abnormal readings may trigger unnecessary emergency alerts.


STRATEGIES TO OVERCOME CHALLENGES

- Communication failure → Use LoRa + store-and-forward with multiple communication paths where possible.

- Battery limitation →Use low-power modes, adaptive sensor sampling, and battery monitoring.

- Positioning errors → Combine GNSS + IMU + UWB* using sensor-fusion algorithms.

- Harsh conditions →Use a rugged, waterproof enclosure and protected connectors.

- False alerts → Use multi-sensor confirmation + edge intelligence before triggering an emergency alert.


ANTI-JAMMING COMMUNICATION STRATEGY

FHSS: Rapidly changes the communication frequency to make sustained interference more difficult.

- Directional Antenna: Focuses the radio signal toward the intended gateway, reducing exposure to interference from other directions.

- Fallback & Storage: If communication is temporarily lost, store critical data locally and transmit it when the link recovers.
